 # Ghost Mode Status Board 🚀

A sleek, dark-themed command center built to track deep work sessions and daily hydration. 

## 🧠 The Concept
This project was designed as a daily driver to maintain high-performance habits. It utilizes a custom JavaScript engine to track tasks, inject real-time military timestamps, and save data directly to the browser's local storage so nothing is lost upon refresh.

## 🛠️ Built With
* **HTML5:** Semantic structure and layout.
* **CSS3:** Flexbox logic, custom dark-mode aesthetics, and clean UI design.
* **Vanilla JavaScript:** DOM manipulation, event listeners, and timekeeper logic.
* **Local Storage API:** Persistent data rendering without a backend server.

## ⚙️ Features
* **Live Timestamping:** Automatically pulls the browser's atomic clock and formats it into 24-hour military time for every logged task.
* **Persistent Memory:** Survives browser refreshes by writing directly to `localStorage`.
* **The CRUD Cycle:** Full ability to Create, Read, and Delete specific data nodes on command.
